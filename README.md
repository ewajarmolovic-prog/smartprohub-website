# SMARTPRO HUB

Statyczna, dwujęzyczna strona [smartprohub.io](https://smartprohub.io/) przygotowana do publikacji przez GitHub Pages.

## Struktura

- `/index.html` — polska wersja strony
- `/en/index.html` — angielska wersja strony
- `/assets/` — style, skrypty i grafiki
- `/robots.txt` — reguły indeksowania
- `/sitemap.xml` — mapa strony PL/EN
- `/CNAME` — domena własna GitHub Pages

Publikacja uruchamia się automatycznie po wysłaniu zmian do gałęzi `main`. W ustawieniach repozytorium GitHub Pages źródłem publikacji powinno być **GitHub Actions**.
